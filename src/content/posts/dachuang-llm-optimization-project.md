# 大创项目：基于量化和蒸馏的强化学习 LLM 模型优化

这是我们大创项目的开题思路。项目名挺长：**基于量化和蒸馏的强化学习 LLM 模型优化**。翻译成人话：在尽量低的成本下，把小模型的推理能力拉到接近大模型的水平。

## 项目想干什么

我们原本的计划，是对预训练模型采用"监督微调（SFT）+ 强化学习（RL）"的组合来训练。后来 DeepSeek 发布了 R1 系列，给了我们很大启发——他们把量化、蒸馏和强化学习三个工具拧成一个优化框架：量化把存储和计算成本打下来，蒸馏把大模型的知识搬进小模型，RL 再让模型在复杂任务里长出更强的泛化能力。

但我们也看到了纯 RL 路线的另一面：DeepSeek 自己也承认，单纯靠 RL 会带来奖励黑客、泛化失败、语言混合和高计算成本等一堆挑战。所以我们的想法是：**在量化 + 蒸馏的框架上，结合 RL 和 SFT 的混合训练方法**——用 SFT 稳住基础能力，用 RL 打磨推理质量，在低成本的前提下把推理能力和输出质量都提上去。

一句话概括项目目标：低成本、高推理质量。

## 参考的三篇关键论文

开题阶段我们重点读了这三篇，思路基本是从它们长出来的：

**1. RL 的无害性局限与混合训练。** 这篇讨论强化学习在减少 DeepSeek-R1 这类高级模型有害输出上的局限性，并和 SFT 做了对比。结论是：RL 能提高推理能力，但面临奖励黑客、泛化失败、语言混合和高计算成本等挑战，于是提出了结合 RL 和 SFT 的混合训练方法，来实现可靠的无害性削减——这正是我们项目训练策略的直接来源。

**2. 量化 + 蒸馏 + RL 优化框架。** 这篇提出结合量化、蒸馏和强化学习的优化框架：量化降存储计算成本，蒸馏做知识迁移，RL 提升复杂任务上的泛化能力和性能。实验表明量化蒸馏后的模型在推理任务上和原始大模型性能相近，计算资源消耗却显著减少——这是我们框架的主心骨。

**3. SFT + 可控 RL 的两阶段微调。** 这篇讲的是把 LLM 微调成"更好的想法提出者"：SFT 阶段让模型从论文和后续想法的配对中学习基础模式，RL 阶段用细粒度反馈引导的多维奖励建模评估优化生成内容，维度控制器动态调整生成。它给我们的启发是：混合训练里"阶段怎么排、奖励怎么设计"，都有讲究。

## 接下来的路

项目会沿着"量化蒸馏打底 → SFT 稳住 → RL 提上限"的路线推进，具体实验设计和结果后面再更新。毕竟大创嘛，先把可行性验证跑通，再谈性能数字。
