用 Debian 的时候，我一度怀疑自己是不是装了个假 vi。明明老老实实按方向键，屏幕上蹦出来的却是 A、B、C、D 这样的字母；想退格删个字，退格键直接装死，一个字都删不掉。当时整个人都懵了：这还怎么写代码、改配置啊？

冷静下来查了一圈，才发现这锅不该 vi 背，是配置的锅：Debian 的 vi 默认跑在**兼容模式**下，方向键和退格键的行为就变得奇奇怪怪。解决办法特别简单，改一个配置文件、加两行就搞定。

## 解决方法

用 vi 编辑 `/etc/vim/vimrc.tiny`（这是系统目录，记得加 root 权限，不然没资格保存）：

```bash
sudo vi /etc/vim/vimrc.tiny
```

进去之后按 `i` 进入插入模式，加上两行配置：

```
set nocompatible
set backspace=2
```

然后按 `Esc` 退出插入模式，输入 `:wq` 保存退出。重新打开 vi 试试，方向键和退格键都恢复正常了，前后不到 30 秒。

## 这两行到底干了啥

- `set nocompatible`：让 vim 退出兼容模式。兼容模式下 vim 会模仿老式 vi 的怪脾气，把方向键的按键序列当成普通字符处理，于是屏幕上就冒出了 ABCD。退出兼容模式，方向键立马恢复理智。
- `set backspace=2`：允许退格键跨行、跨缩进删除。默认配置把退格键限制得死死的，删不动东西，这一行一加，退格键立刻活蹦乱跳。

## 为什么改的是 vimrc.tiny

Debian 上的 vi 其实是精简版 vim（vim.tiny），它读的配置文件就是 `/etc/vim/vimrc.tiny`。改这一个文件，系统里所有调用 vi 的地方都生效，一劳永逸。如果只想影响当前用户，也可以写到用户目录下的 `~/.vimrc` 里，效果类似，只是作用范围小一点。

## 常见疑问

- **改完还是老样子？** 先确认 `:wq` 真的保存了，再看一眼编辑的是不是 `/etc/vim/vimrc.tiny` 这个文件，别改到别的 vimrc 去了。
- **为什么只有 Debian 这么别扭？** Debian 把 vi 指向精简版 vim，而且默认开了兼容模式，才闹出这么一出。换个发行版可能压根遇不到。
- **vi 和 vim 有啥区别？** 在 Debian 上，你敲 vi 实际跑的就是 vim 的瘦身版，所以这个配置对 vi 和 vim 都管用。

## 小结

- 出问题的是 vi 的兼容模式，不是你的操作，别自我怀疑。
- 核心配置就两行：`set nocompatible` + `set backspace=2`。
- 改的是 `/etc/vim/vimrc.tiny`，对系统里的 vi 调用都生效。

如果你也遇到过 vi 方向键乱码、退格键失灵的问题，别急着换编辑器，先试试这两行，基本一次搞定。
