2025 年 1 月，DeepSeek 放出了 R1 论文（arXiv 2501.12948），同时开源了完整模型和蒸馏小模型。我读完最大的感受是：**这篇论文证明了「推理能力不需要被教，只需要被激励」——给模型一个正确的奖励信号，它自己会长出反思、验证、顿悟这些高级行为**。而更让我意外的是第二件事：**把大模型的推理能力「蒸馏」给小模型，比直接在小模型上做强化学习便宜得多，效果还好得多**。

这篇文章是我的精读笔记，按论文的结构走：先看 R1-Zero 怎么用纯强化学习逼出推理能力，再看 R1 怎么用冷启动 + 四阶段流水线把它打磨成好用的产品，最后是蒸馏和实验结果，以及我的一些理解。

## 这篇论文做了什么：一句话版

DeepSeek 做了三个东西：

1. **DeepSeek-R1-Zero**：直接在 DeepSeek-V3-Base 上做大规模强化学习，**完全不经过监督微调（SFT）**，验证了推理能力可以纯粹靠 RL 涌现出来；
2. **DeepSeek-R1**：在 RL 之前加入少量冷启动数据和多阶段训练，推理性能对齐 OpenAI-o1-1217，而且输出可读、不混语言；
3. **六个蒸馏小模型**（1.5B / 7B / 8B / 14B / 32B / 70B，基于 Qwen 和 Llama）：只用 SFT 微调，小模型就获得了接近 o1-mini 的推理能力。

## 背景：为什么这篇论文值得读

论文的开头很直白：OpenAI 的 o1 系列第一个把「推理时扩展」（test-time scaling）做成产品——让模型生成更长的思维链，在数学、代码、科学推理上效果显著。但 o1 是闭源的，大家只看到结果，看不到方法。学界尝试过过程奖励模型（PRM）、搜索算法（MCTS、束搜索）等路线，都没能复现 o1 级别的通用推理能力。

DeepSeek 这组的切入点是：**后训练才是关键**。预训练成本高，但后训练相对便宜，而且能大幅提升推理能力。他们选了最激进的一条路——纯 RL，一点监督数据都不给，看模型能不能自己进化出推理能力。

![DeepSeek-R1 论文配图：模型整体框架](/images/posts/deepseek-r1-paper-reading/01.webp)

## 核心贡献一：R1-Zero，纯强化学习逼出推理能力

R1-Zero 是整个论文最「实验性」的部分：拿 DeepSeek-V3-Base 当底座，直接跑大规模强化学习，没有 SFT 冷启动。结果 AIME 2024 的 pass@1 从训练前的 **15.6% 一路涨到 71.0%**，多数投票（cons@64）还能到 86.7%，追平了 OpenAI-o1-0912。要知道，这个模型从头到尾没见过一道带答案的数学题。

![R1-Zero 在 AIME 2024 上的性能提升（论文原图）](/images/posts/deepseek-r1-paper-reading/02.webp)

### GRPO：不要价值网络，用一群答案互相比较

RL 训练的算力开销大头之一是价值模型（critic），它和策略模型一样大。DeepSeek 用的是 **GRPO（群组相对策略优化，Group Relative Policy Optimization）**，直接把这个网络砍掉了。

思路很朴素：对同一个问题，从旧策略里采样**一组**输出（比如 G 个），用这一组答案的分数互相比较来算优势——某个答案的优势 =（自己的奖励 − 组内平均奖励）÷ 组内标准差。也就是说，不跟一个绝对标准比，只跟「同组其他答案」比。然后优化目标就是在旧策略附近做带裁剪的更新，同时用 KL 散度约束住，别让新策略跑太远。

GRPO 的核心就一句话：**省掉一个和策略一样大的网络，用组内相对排名代替绝对价值估计。**

### 基于规则的奖励：简单，但不容易被钻空子

奖励是 RL 的「老师」，决定了模型往哪个方向长。R1-Zero 只用两种**基于规则**的奖励，刻意不用神经网络奖励模型：

- **准确率奖励**：数学题有确定性答案，要求模型把最终答案放在指定格式里，直接比对正确与否；LeetCode 类题目直接丢给编译器跑测试用例；
- **格式奖励**：强制思考过程放在 `<think>...</think>` 标签之间。

为什么不用神经奖励模型？论文的理由很实在：在大规模 RL 中，神经奖励模型容易被**奖励黑客（reward hacking）**钻空子，而且重新训练奖励模型要额外资源，把整个流程搞复杂。规则奖励简单、可验证、不可欺骗——这是后面所有成功的地基。

另外，训练模板刻意做得极简：只规定「先思考、再回答」的结构，**不塞任何内容层面的偏见**（比如不强制反思、不指定解题策略），这样才能干净地观察模型自然会长出什么。

### 自我进化与「顿悟时刻」

这是全文最让我起鸡皮疙瘩的部分。随着 RL 训练推进，几个现象是自发出现的，没人编程教过：

- **思考时间持续变长**：从几十个 token 涨到数百甚至数千个推理 token，模型「学会」了用更多时间换正确率；
- **反思行为涌现**：模型会回头重新审视、重新评估自己之前的步骤；
- **探索替代方案**：一条路走不通会换一条路。

![R1-Zero 训练过程中输出长度的变化（论文原图）](/images/posts/deepseek-r1-paper-reading/03.webp)

最著名的是「顿悟时刻」——训练中期的一个版本，模型在解一道数学题时突然说：「**等等，等等。等一下。这是一个我可以标记的顿悟时刻。**」然后它重新评估自己的初始方法，从头再推一遍。模型并没有被教过「要自我怀疑」，它是自己学会的。

论文里那句话我特别喜欢：**这一刻不仅是模型的顿悟时刻，也是观察它的研究人员的顿悟时刻——我们不用教它怎么解决问题，只要给对激励，它就能自主发展出高级解题策略。**

### R1-Zero 的短板

但纯 RL 长出来的东西不好用：**可读性差**——思考过程经常中英文混杂、没有 markdown 格式、输出乱糟糟。这直接催生了 R1。

## 核心贡献二：R1，冷启动 + 四阶段流水线

R1 要回答两个问题：加一点高质量数据能不能既提速又提性能？能不能训练出一个「说人话」的用户友好模型？答案是论文里的四阶段流水线。

### 阶段一：冷启动

先用**几千条**长思维链数据微调 DeepSeek-V3-Base。这些数据怎么来？长 CoT 少样本提示、让模型用反思和验证生成详细答案、收集 R1-Zero 的可读输出并人工后期处理。关键设计：输出格式固定为「`<推理过程>` + `<摘要>`」，每条响应末尾强制加摘要，过滤掉不可读的样本。

冷启动的两个收益：**可读性**（格式统一、有摘要、不混语言）和**潜力**（融入人类先验后，性能直接超过 R1-Zero——论文认为迭代训练是推理模型的更优路径）。

### 阶段二：面向推理的强化学习

在冷启动模型上跑和 R1-Zero 一样的大规模 RL，主攻数学、代码、科学、逻辑这类「定义明确、答案可验证」的任务。

这里有个细节值得注意：训练中思维链经常出现**语言混合**（提示是什么语言都可能跑出英文思考）。R1 引入了一个**语言一致性奖励**——计算思维链中目标语言单词的占比。消融实验显示这个奖励会带来一点性能下降，但它符合人类偏好、让输出可读，所以保留。最终奖励 = 推理准确率 + 语言一致性。

### 阶段三：拒绝采样 + 监督微调

RL 收敛后，用当前检查点生成新数据，把能力面从「纯推理」扩到「通用能力」：

- **推理数据（约 60 万条）**：对推理提示做拒绝采样，只保留回答正确的轨迹；过滤掉语言混杂、长段落、带代码块的思维链；部分数据用 DeepSeek-V3 当生成式奖励模型做判断；
- **非推理数据（约 20 万条）**：复用 DeepSeek-V3 的 SFT 数据，覆盖写作、事实问答、自我认知、翻译；简单查询（比如「你好」）不给 CoT。

总共约 80 万条样本，对 Base 模型微调两个 epoch。

### 阶段四：全场景强化学习

最后一轮 RL 的目标是**有用性 + 无害性 + 推理**三合一：推理数据继续用规则奖励；通用数据用奖励模型捕捉人类偏好。细节上有个很聪明的处理：评估有用性时**只看最终摘要**，不干扰推理过程；评估无害性时则看**完整响应**（包括推理过程），防止风险内容藏在思维链里。

四阶段跑完，DeepSeek-R1 在推理任务上对齐 OpenAI-o1-1217。

## 核心贡献三：蒸馏，小模型同样强大

这是我觉得**对普通人价值最大**的部分。做法极其简单：把 R1 当老师，用那 80 万条样本直接 SFT 微调 Qwen2.5-Math-1.5B/7B、Qwen2.5-14B/32B、Llama-3.1-8B、Llama-3.3-70B，**不加 RL 阶段**（把 RL 的探索留给社区）。

效果惊人：

- **7B 模型**在 AIME 2024 上拿到 55.5%，超过 32B 的 QwQ-32B-Preview（50.0%）；
- **14B 模型**在所有评估指标上全面超越 QwQ-32B-Preview；
- **32B 和 70B**在大多数基准上显著超过 o1-mini；
- 甚至 **1.5B 模型**在数学基准（AIME 28.9%、MATH-500 83.9%）上都超过了 GPT-4o 和 Claude-3.5-Sonnet。

论文还专门做了对照实验回答一个问题：小模型不蒸馏、自己上大规模 RL 行不行？他们用 Qwen-32B-Base 跑了 **超过 1 万步** 的 RL，得到 R1-Zero-Qwen-32B——性能只跟 QwQ-32B-Preview 相当，而蒸馏出来的 32B 在所有基准上全面碾压它。结论很清晰：**蒸馏更强模型的推理模式，比在小模型上烧算力做 RL 划算得多**；但想突破智能边界，还是得靠更强的基座 + 更大规模 RL。

## 实验结果：挑几个数字

R1 对 OpenAI-o1-1217 的全景对比（pass@1）：

- **数学**：AIME 2024 **79.8%**（o1-1217 为 79.2%）；MATH-500 **97.3%**（96.4%）；中国数学奥赛 CNMO 2024 78.8%；
- **代码**：Codeforces 评级 **2029**，超过 96.3% 的人类参赛者（o1-1217 为 2061）；LiveCodeBench 65.9% 超过 o1-1217 的 63.4%；SWE Verified 49.2% 与 o1 相当，但 Aider 53.3% 落后于 o1 的 61.7%（论文坦承工程类 RL 数据太少，下个版本改进）；
- **知识**：MMLU 90.8%、MMLU-Pro 84.0%、GPQA Diamond 71.5%，全面超过 DeepSeek-V3，略低于 o1-1217；
- **通用**：AlpacaEval 2.0 长度控制胜率 87.6%、ArenaHard 92.3%，长上下文 FRAMES 82.5% 超过 o1-1217。

评估设置也有讲究：输出上限 32,768 token；因为贪心解码在长输出推理模型上重复率高，改用温度 0.6、top-p 0.95 采样 K 条算 pass@k。

## 论文还踩过的坑：PRM 和 MCTS

论文专门开了一节「失败的尝试」，我很欣赏这种坦诚：

- **过程奖励模型（PRM）**：三个硬伤——通用推理里很难定义细粒度的「步骤」；判断中间步骤对不对本身很难（自动标注质量不行，人工标注没法规模化）；基于模型的 PRM 必然招来奖励黑客，重训又贵。PRM 更适合做重排序或引导搜索，在大规模 RL 里性价比不高；
- **蒙特卡洛树搜索（MCTS）**：被 AlphaGo 启发，但 token 生成是**指数级搜索空间**，跟棋盘完全不同；限制扩展次数会陷入局部最优；细粒度价值模型极难训练，AlphaGo 那套「价值模型驱动自我提升」在语言生成上复制不了。

## 局限与未来方向

- **通用能力**：函数调用、多轮对话、复杂角色扮演、JSON 输出还不如 DeepSeek-V3，未来想用 CoT 补上；
- **语言混合**：只针对中英文优化，其他语言的查询可能跑出英文思维链；
- **提示敏感**：少样本提示会稳定掉性能，论文建议**直接描述问题 + 零样本指定输出格式**——这对我们日常使用 R1 是条很实用的建议；
- **软件工程**：评估耗时太长拖慢 RL 流程，计划用拒绝采样或异步评估解决。

## 我的理解与读后感受

最后说几点我自己的理解，仅基于论文内容：

1. **「激励设计 > 内容教学」**。R1-Zero 的顿悟时刻是最有冲击力的证据：模型从没被教过反思，只是被奖励「正确答案 + 格式正确」，就在几万步内自己演化出验证、重估、长思考。这暗示 LLM 的预训练知识里其实已经藏了推理的潜力，RL 只是把它「激活」了。对做 RL 的人来说，最大的杠杆可能不是更多的数据，而是更干净的奖励函数。

2. **规则奖励赢在「不可欺骗」**。论文反复强调奖励黑客和神经奖励模型的成本，最终选择只有准确率 + 格式两条规则。这个选择看似简单，其实是把「什么是对的」定义得无懈可击——数学题的答案和编译器的测试用例是唯一可信的真值。等任务变得开放（写作、对话），他们就换回奖励模型了，说明**奖励的「可验证性」决定 RL 的稳定性**。

3. **蒸馏是这篇论文最「普惠」的贡献**。1.5B 模型在数学上超过 GPT-4o，7B 打平 QwQ-32B-Preview，这意味着推理能力第一次可以被塞进跑得动的模型里。论文的对照实验（1 万步 RL 不如直接蒸馏）也提醒我：**算力不足时，站在巨人的肩膀上比从头爬更划算**。这可能也是开源社区最关心的一条路。

4. **可读性不是小事**。R1-Zero 证明了能力，R1 才证明了「能用」。冷启动 + 摘要 + 语言一致性奖励，做的全是工程化的「产品感」打磨——论文想说的其实是：纯 RL 能长出能力，但**人类的先验知识决定了它长成什么形态**。

一句话总结：这篇论文用最干净的实验（R1-Zero）证明了 RL 能激励出推理，用最实用的流水线（R1）把它变成产品，再用最便宜的方案（蒸馏）把它普惠给所有人。三件事，每一件都值得读。
